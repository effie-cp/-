# AI 채팅 플랫폼 크리에이터 제도 조사

크플 전속 크리에이터 제도 설계를 위한 경쟁사 정산·제도 벤치마킹 자료.

## 파일

| 파일 | 설명 |
|---|---|
| `플랫폼_크리에이터_제도_비교.xlsx` | 최종 산출물. 6시트 |
| `data.json` | 정규화된 원자료 (플랫폼별 전체 필드) |
| `build.py` | 엑셀 생성 스크립트. `data.json`이 아닌 스크립트 내 리터럴을 소스로 사용 |

## 엑셀 시트 구성

1. **전속 제도** — 자사에만 작품을 올리는 조건의 크리에이터 단위 계약. 19사 × 18항목
1-2. **계약형 7사** — 계약 제도가 있고 내용이 확인된 7곳(케이브덕·베이비챗(투킷)·스토리엔진·젠잇·티팟·둠칫·에덴챗)만 계약 관점(단위·독점·체결·의무·환수·IP)으로 재구성
2. **비전속 제도** — 일반(계약 없음) 15항목 + 독점작(작품 단위) 12항목
3. **정산 단가** — 모델별 채팅 1건당 크리에이터 실수령액. 수식 연동
4. **등급표** — 베이비챗 크리에이터 클럽 5등급 / 루나톡 공식 크리에이터 5등급
5. **출처·미확인** — 출처, 원문 충돌 8건, 미확인 13건(우선순위)
6. **시사점** — 관찰 15개 (전속 8 / 비전속 5 / 공통 2)

## 조사 대상 (2026-08-19 기준, 19개)

| 플랫폼 | 정산 구조 | 전속·독점 제도 |
|---|---|---|
| **케이브덕** | 인센티브 정액제 (1pt = 0.6원, 1윙 = 1원). 부가 수익원 정산율 확정: 이미지 30% / 스토리 20% / 보이스 6% / 스냅샷 4% / 윙 선물 80~90%. 채팅 정산율은 소모 윙 수만 미확인 | 공식 크리에이터 — 신규작 영구 독점, 위반 시 적립금 전액 소급 회수 |
| **베이비챗 (투킷)** | 응원하기 정률 + 베리 적립 (실질 1.0~2.3%) | 공식 크리에이터 — 초대 전용, 전면 전속 / B Only 100일 |
| **스토리엔진** | 크레딧 정액제 (1크레딧 = 7원) | 파트너 크리에이터 — 전면 전속, 정산율 우대 없음 |
| **루나톡** | 후원 포인트 90~97% (채팅 정산 미확인) | 공식 크리에이터 5등급 — 독점 요구 없음, 타 플랫폼 활동작가를 모집 대상으로 명시 |
| **에덴챗** | 확인 불가 — 요율표 없이 제작자별 개별 협의 | 공식 계약 크리에이터 — 계약 기반이나 독점 요구는 없음 (문서 명시) |
| **페이브챗** | 미공개 — 약관 제28조 ⑧ 기밀유지 의무 | 공식 크리에이터 — 존재만 확인 |
| **엘린** | 캐릭터 사용액의 3%(본인인증) / 8%(인증 크리에이터) | 없음 |
| **젠잇** | 유료 사용 금액의 5~50% (튜닝 모델 현금 / 그 외 젤리) | 작품 단위 퍼블리싱 계약. 타 서비스 작품을 내려 만든 독점은 불인정 |
| **플레이툰** | 10% → 블루젬 교환가치 30% → 실질 약 3% | 없음 |
| **챗플** | 이벤트 — 유저 1턴당 5~10원 (상시 요율 미확인) | 공식 크리에이터 — 계약 기반, 내용 미공개 |
| **위프** | 기준 요율 비공개. 프라임 2배 / 하이퍼 2.5배만 공개 | 없음 (타이틀 작가는 실적 등급제) |
| **둠칫** | 티어 3~15% + 공식 2% + 독점공개 3% 또는 오리지널 5% (최대 22%). 출금 1,000,000P = 60,000원 | 공식 크리에이터(독점 없음) / 독점공개 3개월 / 오리지널(저작권 매입) |
| **티팟** | 유료 리프의 8%(자유) / 12%(독점). 1리프 = 1원. 현금 환산 85.53% | 독점 크리에이터 3개월 갱신 / 캐릭터별 독점 전환 가능 |
| **우마이** | 유료 캐롯의 5%(기본) / 8~12%(인증) — 원문상 '예정' 단계 | 인증 크리에이터 — 독점 요구 미확인 |
| **유니챗** | 유료 스텔라의 10% 현금. 1스텔라 = 1원. 2026.07.01~2028.06.30 **2년 확약** | 없음 |
| **이세계트럭** | 10% — 모수·조건 일체 미확인 | 없음 |
| **팅글** | 수익배분율 20% — 단 **모수가 「마진」**(고객센터 답변). 마진율 미공개로 실질 산출 불가 | 없음 |
| **로판AI** | 소모 포인트의 10%(일반) / 30%(R ONLY) / 파트너 40~50%. **제보 기준 실질 0.71~3.56%** | R ONLY(작품 독점) / 파트너 크리에이터 실버·골드·플래티넘 |
| **멜팅** | 유료 콘의 1%(포인트)·2%(콘 환산) / 멜팅온리 1.5%·3%. 첫 장면 해금 25%. 1포인트 = 12원 | 멜팅온리(작품 독점) / 앰배서더 크리에이터 — 계약 내용 비공개 |

미수집: 제타

## 읽을 때 주의

- **표기 요율 ≠ 실질**: 플레이툰 10%→3%, 베이비챗 10~23%→1.0~2.3%. 플랫폼 재화로 적립한 뒤 사용 단계에서 한 번 더 깎이는 2단 구조. 팅글 20%도 전환 비율 미확인이라 같은 가능성이 남아 있음
- **모수 유형이 세 갈래**: ① 유저 결제액 기준(티팟·유니챗 — 재화 단가 1원이라 결제액 대비 비율이 그대로 성립) ② 재화 소모량 기준(젠잇·둠칫·로판AI 등 8곳) ③ **마진 기준(팅글 — 크리에이터가 검증 불가)**. 모수를 밝힌 곳은 19곳 중 10곳뿐이고, 결제액 대비로 바로 읽히는 곳은 2곳뿐
- **현금화 게이트**: 현금 출금을 막거나 등급·인증 뒤에 둔 곳 5곳 — 멜팅(3단계째 파트너부터),  — 베이비챗(경로 없음), 플레이툰(기프티콘만), 위프(프라임 이상만), 페이브챗(인증 후만)
- **환수 조항**: 케이브덕(기간 내 적립금 전액)·팅글(블락 전 수익까지 + 환불 연동)이 가장 광범위, 둠칫(보너스분만)이 가장 절제, 티팟은 없음
- **정산률 변경 리스크**: 대부분 "사전 고지 없이 변경 가능"을 명시. 기간을 확약한 곳은 유니챗(2년)뿐
- **독점작 제도는 19곳 중 7곳뿐**: 로판AI(R ONLY 30%) · 젠잇(퍼블리싱 20~50%) · 티팟(캐릭터별 전환 12%) · 둠칫(독점공개 +3%p) · 베이비챗(B Only) · 케이브덕(오리지널). 셀프 선택이 가능한 곳은 티팟·베이비챗·케이브덕 3곳
- **표기 요율과 실질이 뒤집힘**: 로판AI R ONLY는 표기 30%지만 제보 기준 실질 약 2.1% (1/14) — 크레딧 1개의 현금 가치가 0.64원인데 유저 측 포인트는 9원이라 현금화 단계에서 대부분 깎임. 베이비챗 1/10, 플레이툰 1/3.3. 팅글 20%도 전환 비율 미확인. **요율만으로 순위를 매기면 정확히 상위권에서 오판하게 됨**
- **한시 프로모션**: 젠잇 채팅수 지원 26.08.31 종료, 베이비챗 선물 2026 한정, 챗플 이벤트 진행 중, 우마이는 요율 자체가 '예정'. 경쟁사 수치를 기준선으로 삼을 때 걷어낼 것

## 갱신 방법

`build.py`의 데이터 리터럴을 수정한 뒤:

```bash
python3 build.py
python3 <xlsx-skill>/scripts/recalc.py 플랫폼_크리에이터_제도_비교.xlsx 300
```

recalc은 LibreOffice Calc(`libreoffice-calc` 패키지)가 필요하다.

## 원칙

- 원문에 없는 값은 추정하지 않고 `미확인`으로 남긴다
- 문서 간 값이 충돌하면 양쪽을 모두 기록하고 채택 근거를 남긴다 (5번 시트)
- 근거 등급: 공식 / 제보 / 추정 / 미확인
